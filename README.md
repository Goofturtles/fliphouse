# Fliphouse

Live Hypixel Skyblock auction-house flip finder. Scans every BIN auction straight from the public Hypixel API in your browser, finds items listed under market, and shows what to buy, what to relist it for, and what you clear after tax — filtered to your budget.

**Live:** https://goofturtles.github.io/fliphouse/

- Real demand data: samples actual sold auctions every minute for sells/day and real sold prices
- Budget presets with a ready-made shopping list
- Settings: resale basis (undercut / median / recent sold), lots per item, min supply, auto-rescan
- No API key, no server, no build — four static files

Prices move fast; rescan before you buy. Not affiliated with Hypixel.
